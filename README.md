# Become Her

A daily ritual dashboard: four morning questions, affirmations said three times a day with a time log, and a morning and night gratitude log.

- `index.html` is the whole dashboard. Open it in a browser or host it with GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder).
- `become-her-reminders.ics` adds the daily 6:00 AM, 12:00 PM, 5:00 PM and 9:00 PM reminders (Central Time) to Google Calendar or iPhone Calendar.
- Entries are saved in the browser's local storage. Use "Copy all entries (JSON)" on the page to back them up.
- Affirmations rotate through four weekly sets, changing every 7 days from the first day the page is opened. Edit any week's set from the page.
